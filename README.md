A sentient smart toaster breaks up with its owner at breakfast: "You set me to "dark" every morning, then act surprised when I run off with the toaster oven and the bagels."

## Run it

```sh
python3 main.py
```

## Why this line

The toaster speaks in its own vocabulary: the "dark" dial setting is both
a breakfast instruction and the relationship grievance. The punchline
lands on the affair — the toaster oven, plus the bagels, walked out the
door with it.
